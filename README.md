# 简历微信小程序

基于微信原生小程序与微信云开发的简历优化助手。代码工程位于 [`miniprogram/`](miniprogram/)，请在微信开发者工具中打开这个目录。

## 功能

- 上传 DOCX 或可提取文字的 PDF，并由用户核对提取结果
- 基于确认后的简历事实匹配岗位方向并生成定制简历
- 编辑、确认生成版本，并导出 DOCX、PDF 和页面预览
- 通过云函数隔离用户数据、生成额度和模型调用

## 开始使用

1. 安装微信开发者工具，并导入仓库中的 `miniprogram/` 目录。
2. 在云开发控制台配置对应环境、数据库集合和存储安全规则，参考 [`docs/`](docs/) 中的部署说明。
3. 将 DeepSeek API Key 配置在 `careerAssistant` 云函数服务端环境变量中，不要写入小程序代码或提交到仓库。
4. 按 `miniprogram/README.md` 中的本地校验命令运行检查，再部署所需云函数和云托管服务。

## 目录

- `miniprogram/`：小程序、云函数、云托管渲染服务、测试与部署配置
- `docs/`：P2 至 P5 阶段云端部署说明
- `DESIGN.md`、`PRODUCT.md`：产品与技术设计资料

项目环境 ID 等运行环境参数请按自己的云开发环境核对。用户简历等个人数据不要提交到代码仓库。
